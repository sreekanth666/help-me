# Third-party notices

The media converter runs in the browser using these libraries. They are used unmodified.

| Library | Licence | Used for |
|---|---|---|
| [mediabunny](https://github.com/Vanilagy/mediabunny) | MPL-2.0 | Reading and writing MP4 and WebM; WebCodecs-based encoding |
| [@mediabunny/aac-encoder](https://github.com/Vanilagy/mediabunny) | MPL-2.0 | AAC audio where the browser has no encoder. Embeds FFmpeg's native AAC encoder (LGPL-2.1-or-later) |
| [@jsquash/webp](https://github.com/jamsinclair/jSquash) | Apache-2.0 | WebP encoding (lossless, and browsers without native WebP encoding). Embeds libwebp (BSD-3-Clause) |
| [client-zip](https://github.com/Touffy/client-zip) | MIT | Building the ZIP download |

MPL-2.0 is file-level copyleft: changes to those libraries' own files must be published under the
same licence. We do not modify them.

No code from VERT (AGPL-3.0) is used.
